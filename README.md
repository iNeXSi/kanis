# كانس | Kanis

أداة محلية لويندوز لمراجعة الملفات المؤقتة ومساحة الأقراص ومراقبة الرام. واجهة عربية وإنجليزية، وضع فاتح وداكن، وأذكار اختيارية. لا حسابات أو رفع لملفاتك.

**[تحميل آخر إصدار لويندوز](https://github.com/iNeXSi/kanis/releases/latest)**

## البداية

1. نزّل `Kanis-v0.6.0-Windows-x64.zip` من Releases.
2. فك الضغط كاملًا في مجلد ثابت، ثم شغّل `Kanis.exe`. لا تشغّله من داخل ZIP ولا تنقل ملف EXE وحده.
3. من «التنبيهات والوصول» فعّل التشغيل مع ويندوز إذا أردت مراقبة المساحة في الخلفية.
4. إغلاق النافذة يبقي كانس بجوار الساعة؛ قد تكون الأيقونة داخل قائمة السهم. النقر المزدوج عليها أو `Ctrl+Shift+N` يعيد النافذة. اختر «إنهاء» لإيقافه.

يستهدف Windows 10/11 بنظام x64. لا يحتاج التشغيل المعتاد إلى مسؤول. وظائف الفحص الموسع وتجهيز RAMMap تطلب موافقة ويندوز عند الحاجة.

## الوظائف

- قراءة مساحة جميع الأقراص الجاهزة والرام، مع تحديث قابل للتعديل.
- فحص Temp وتقارير الأعطال وكاش Chrome وEdge وBrave وnpm وpip والرسوميات. راجع الملفات قبل التنظيف.
- النقل إلى سلة المحذوفات هو الافتراضي. الحذف النهائي يحتاج تأكيدًا إضافيًا. النقل للسلة لا يحرر مساحة القرص.
- حماية الملفات الحديثة، والاستثناءات، والروابط والجسور والملفات متعددة الروابط. يعاد التحقق من الملفات وعمليات التطبيقات قبل التنظيف.
- خريطة أحجام لمجلد أو قرص تختاره، وبحث عن الملفات الكبيرة. قد تكون النتائج جزئية بسبب صلاحيات ويندوز وحدود الفحص.
- تقارير دورية وتنبيهات انخفاض مساحة القرص، مع التحكم بالمدة والحدود. ظهور الإشعارات يخضع لإعدادات ويندوز وعدم الإزعاج.
- أذكار متغيرة في الرئيسية، مع التحكم بالمدة وإيقاف التبديل.
- التشغيل عند تسجيل دخول حسابك بعد 20 ثانية عبر مهمة خاصة بحسابك. الإيقاف من التطبيق يزيل هذه المهمة. بعد نقل مجلد البرنامج، عطّل الخيار وأعد تفعيله لتحديث المسار.

## تقليل الرام

### RAMMap من Microsoft

RAMMap **غير مرفق**؛ لكل مستخدم تجهيز مستقل:

1. نزّل RAMMap 1.63 من [Microsoft](https://learn.microsoft.com/en-us/sysinternals/downloads/rammap) وفك الضغط.
2. في صفحة الذاكرة اختر `RAMMap64.exe` عبر «اختيار ملف RAMMap».
3. جرّب «تقليل الرام الآن»، وراجع شروط Microsoft ووافق عليها داخل نافذة RAMMap إذا قبلتها.
4. بعدها يمكنك تفعيل التقليل التلقائي. يحتاج التجهيز الأول موافقة مسؤول للحساب نفسه. حساب ويندوز القياسي الذي يستخدم بيانات مسؤول آخر لا يدعم هذا التجهيز التلقائي حاليًا.

حد التشغيل الافتراضي 85%، ويمكن تغييره من 60% إلى 95% أو إطفاؤه. يفحص كل دقيقة، وينفذ بعد قراءتين مرتفعتين، مع عشر دقائق بين المحاولات. يعمل فقط أثناء بقاء كانس في شريط النظام. التشغيل التلقائي للرام متوقف افتراضيًا للمستخدم الجديد.

التقليل يشمل البرامج المفتوحة والخلفية ولا يغلقها. قد يسبب بطئًا مؤقتًا، وقد تعود الذاكرة فور استخدامها؛ ليس ضمانًا لتسريع الجهاز أو لتوفير دائم. يفحص كانس البصمة والتوقيع وتعريف المهمة قبل التنفيذ. لا يوقف حماية ويندوز. إذا تغيّر إصدار Microsoft ولم تعد البصمة تطابق، يُرفض الملف حتى تحديث كانس.

### التحكم بعمليات محددة

التحكم الانتقائي بالخلفية يستخدم مساعدًا مبنيًا من المصدر وغير موقّع. قد يمنعه Smart App Control أو سياسة المؤسسة؛ تعرض الواجهة أنه غير متاح. يبقى مسار RAMMap مستقلًا. **لا تعطّل حماية ويندوز لتشغيله.** التطبيق نفسه ليس إصدارًا موقّعًا باسم ناشر كانس، ولا نضمن قبول جميع سياسات الحماية للحزمة.

## الخصوصية والإزالة

الإعدادات والسجل محليًا في `%APPDATA%\Kanis`. نسخة التنزيل لا تحتوي إعدادات المطور أو سجلاته أو ملفاته أو خطوطه الخاصة. يستخدم الإصدار العام خطوط ويندوز.

لإزالة النسخة: أوقف التقليل التلقائي والتشغيل مع ويندوز من داخل كانس، ثم اختر إنهاء واحذف مجلد التطبيق. تجهيز RAMMap الاختياري ينشئ مهمة باسم `Kanis RAMMap <SID>` ومجلد `%ProgramFiles%\KanisRAMMap`؛ يمكن للمسؤول حذفهما من Task Scheduler وExplorer إذا لم يعد أي حساب يستخدمهما. احتفظ بمجلد بيانات كانس إن أردت استعادة إعداداتك لاحقًا.

## البناء والمساهمة

على Windows x64 مع Node.js 22.12 أو أحدث وnpm و.NET Framework C# compiler الخاص بويندوز:

```powershell
npm ci
npm test
npm run package:win
```

تنتج الحزمة وملف SHA-256 داخل `release/`. المعاينة عبر `npm run dev` تستخدم بيانات أمثلة؛ الوظائف الحقيقية تتطلب نسخة Electron. `npm run build` ثم `npm start` يشغّلانها من المصدر. لا توجد مفاتيح أو خدمات سحابية مطلوبة.

الترخيص MIT لكود كانس. راجع `THIRD_PARTY_NOTICES.md` وتراخيص Electron/Chromium والمكتبات المرفقة. RAMMap يخضع لترخيص Microsoft المنفصل. نتائج التحقق وحدودها في [VALIDATION.md](VALIDATION.md).
